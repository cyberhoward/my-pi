### Ask User (`ask_user`)

Interactive decision prompts with searchable single-select, multi-select, batched questions, and freeform responses.

- Gather relevant evidence before asking and include a concise context summary.
- Use one focused question by default; batch only 2–4 independent decisions.
- Use structured options when useful and reserve prompts for decisions that materially need user input.
- The prompt supports overlay and inline display modes, optional comments, and configurable timeouts.
