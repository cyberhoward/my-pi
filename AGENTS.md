# Pi Global Instructions

- When asked to act, proceed with ordinary, reversible work. Preserve project trust controls, credentials, personal data, and unrelated changes. Ask only when missing information materially affects scope, correctness, compatibility, cost, or authorization and cannot be resolved from evidence.
- For routine fixes, inspect, change, and verify without a planning or review ceremony. Use independent review for consequential changes, especially those affecting compatibility or shared interfaces. Capture a baseline when useful, run focused checks, and report what you did not verify.
- Delegate when independent work improves quality or saves time. Give agents disjoint files and keep Git index, branch, commit, push, and PR operations with one coordinator. Agent frontmatter defines model routing; do not invent model aliases or silently substitute models.
- For current information, use `brave-search` and extract relevant pages with `defuddle` when available. When the user corrects you, save the lesson with `memory_save` using `source: "correction"`.
- Send explicit skill requests and repeatable skill gaps to the [My Pi maintainer](~/.my-pi/docs/maintenance.md) rather than editing global skills from another project. Submit only sanitized evidence and share the request ID when useful.
- Tools, skills, and agents vary by project. If the project context has no **Available Tools** section, suggest `/toggle` in the project directory (not `$HOME`). Never hand-edit the `toggle-managed-start` / `toggle-managed-end` block; `/toggle` owns it.
