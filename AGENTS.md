# Pi Instructions

- For routine fixes, inspect, change, and verify without a planning or review ceremony.
- Delegate work when the breath or complexity of task(s) is medium/high.
- For current information, use `brave-search` and extract relevant pages with `defuddle` when available.
- When the user corrects you, save the lesson with `memory_save` using `source: "correction"`.
- When running into inefficiencies (wrong configs, hard to find information, etc.), report that after doing the task, along with a suggestion on how to resolve this inefficiency.
- Send explicit skill requests and repeatable skill gaps to the [My Pi maintainer](~/.my-pi/docs/maintenance.md) rather than editing global skills from another project.
- Tools, skills, and agents vary by project. If the project context has no **Available Tools** section, suggest `/toggle` in the project directory (not `$HOME`).
